# Illustration

Frame for the brand illustrations. The PNGs' cream is exactly `--paper-1`, so they sit on paper seamlessly with no blend mode.

```jsx
<Illustration src="assets/illustrations/professora-tem-ideias.png" alt="Professora conversando com um robô" variant="framed" />
```

Four illustrations ship with the system (see `assets/illustrations/`). `variant="ink"` for hero/feature placement, `framed` inside content, `plain` when bleeding into the page background. Never crop faces or add color overlays.
