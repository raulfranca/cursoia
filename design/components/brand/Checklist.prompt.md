# Checklist

The "o que você vai aprender" list.

```jsx
<Checklist items={["Escrever prompts que devolvem plano de aula","Adaptar uma atividade para três níveis","Corrigir com apoio da IA sem terceirizar a avaliação"]} />
```

Marker defaults to `check` in chalkboard green. 3–6 items; each item is a full action phrase starting with a verb.
