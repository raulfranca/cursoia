# ModuleCard

A numbered course-module row for programme lists and dashboards.

```jsx
<ModuleCard index="01" title="A IA como colega de planejamento" description="Onde ela ajuda, onde ela erra." duration="45 min" format="Vídeo + prática" />
<ModuleCard index="02" title="Prompts que viram plano de aula" done />
```

`done` swaps the number for a check on solid ink. Stack with `--space-4`; keep descriptions to one line.
