# Badge

Uppercase mono status chip for state and category labels.

```jsx
<Badge tone="brand">Turma aberta</Badge>
<Badge tone="warning" icon="clock">Últimas vagas</Badge>
<Badge tone="outline">Módulo 3</Badge>
```

Tones map to the semantic palette: brand, info, warning, danger, neutral, outline. Text is always short (1–3 words) and sentence-cased in source — CSS uppercases it.
