# Icon

Masked Lucide glyph that inherits `currentColor` — the only icon primitive in this system.

```jsx
<Icon name="arrow-right" size={18} />
```

Any Lucide slug works (loaded from the lucide-static CDN). Sizes used in the brand: 12 (badges), 14–16 (inline), 18–22 (buttons, callouts), 28+ (feature marks). Never recolor directly — set `color` on the parent.
