# IconButton

Circular single-glyph control for toolbars, close buttons and carousels.

```jsx
<IconButton icon="chevron-left" label="Anterior" />
<IconButton icon="bookmark" label="Salvar" variant="solid" />
```

Variants: `outline` (default hairline), `solid` (green fill), `bare` (no border — use inside dialogs and toasts). Minimum size for touch surfaces is `md` (40px); `sm` only in dense desktop UI.
