# Button

The action control: pill-shaped, four variants, three sizes.

```jsx
<Button variant="primary" size="lg" iconRight="arrow-right">Quero participar</Button>
<Button variant="secondary">Ver o programa</Button>
<Button variant="ghost" icon="play">Assistir a aula aberta</Button>
<Button variant="ink">Baixar o guia</Button>
```

`primary` for the single main action per view. `secondary` (ink outline) for the alternative. `ghost` for tertiary/inline. `ink` (ochre + drawn 2px offset shadow) is the "sticker" button — one per page maximum, usually a download or bonus. Add `block` for full-width, especially in emails and forms.
