# Input

Labelled text field, single- or multi-line.

```jsx
<Input label="Seu e-mail" placeholder="voce@escola.br" required hint="Usamos só para enviar as aulas." />
<Input label="O que você quer resolver?" multiline />
```

Focus is an ink border plus a soft ochre ring — never a blue browser default. Pass `error` to switch the hint to terracotta.
